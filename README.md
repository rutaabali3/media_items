# media_items

Optimized WebP media assets converted from the `rutaabali3/media` repository.

All supported source images are preserved with their folder structure and converted to **1080 × 1080 WebP** files using aspect-preserving composition. Non-square source images use a soft blurred background rather than stretching or distorting the subject. Duplicate source filenames with different extensions receive collision-safe suffixes such as `__png.webp`.

- Source images converted: 622
- Output format: WebP
- Output dimensions: 1080 × 1080 pixels
- WebP quality: 82
- Google Sheets: not modified
- Conversion manifest: `conversion-manifest.json`
